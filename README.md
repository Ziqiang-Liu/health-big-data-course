# 健康大数据实践课程

课程按讲次整理。每讲的 `课件/` 存放讲义、学生工作单与实验材料，`作业/` 存放本讲的 Word 作业文件。

## 项目目录

```text
健康大数据实践课程/
├── README.md                 # 项目目录与课程索引
├── .gitignore                # Git 忽略规则
├── session2-变量类型/
│   ├── 课件/
│   └── 作业/
├── session4-统计检验/
├── session5-多重检验/
├── session6-机器学习/
├── session7-线性模型/
├── session8-svm/
└── session9-集成学习/
```

各讲按需在 `课件/` 下设置 `data/`（实验数据）、`notebook/` 或 `notebooks/`（Jupyter 笔记本）、`slides/`（幻灯片）、`scripts/`（实验脚本）和 `assets/`（图表与配套数据）。
